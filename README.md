# Description
repo to learn basics of signal processing.

## Start
Launch everything from the root of the folder.

```
mkdir build
cmake --build build/
python python/gen_input.py
./build/signal_processor 
```

Graphs (in case you go from the very 0):
```
python -m venv  ./my_env
source my_env/bin/activate
pip install pandas
pip install matplotlib
python src/graphs.py 
```

or just `python src/graphs.py `
